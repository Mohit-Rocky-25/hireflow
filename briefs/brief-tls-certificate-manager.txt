----------------------------------------
Manual TLS certificate management causes production outages when certificates expire unexpectedly. Build an automated certificate manager that implements the ACME protocol (used by Let's Encrypt), automatically renews certificates, distributes them across services, and monitors expiry.

----------------------------------------
Cert-manager (Kubernetes), Caddy server, and Traefik all implement ACME automatically. Every website serving HTTPS needs certificate management. Understanding ACME and TLS certificate lifecycle is essential for security and platform engineering roles.

ARCHITECTURE & DATA FLOW
----------------------------------------
Go ACME client implementing DNS-01 challenge for domain validation. Certificate store (PostgreSQL or file system) with expiry tracking. Background goroutine checking expiry and triggering renewal 30 days before. Distribution mechanism pushing renewed certificates to Nginx/HAProxy. Monitoring dashboard with expiry calendar.
