======================================================================

Domain    : Data Engineering

Tech Stack: ClickHouse, Kafka, Node.js, Docker, SQL, TypeScript

PROBLEM STATEMENT
----------------------------------------
SaaS analytics products struggle to query billions of clickstream events in real-time without costly batch compute. Traditional OLTP databases like PostgreSQL time out on analytical queries above 50M rows. Build an analytical ingestion pipeline that streams client telemetry into ClickHouse with instant aggregations.

USE CASES IN THE REAL WORLD
----------------------------------------
Mixpanel, Amplitude, Clevertap, and MoEngage all solve this. In India, companies like WebEngage and CleverTap are building exactly this infrastructure. Any B2B SaaS company with a product analytics offering needs this at scale.

WHY THIS IS HARD (COMPETENCY REDUCER)
----------------------------------------
The gap between OLTP (operational) and OLAP (analytical) databases is one of the most important architectural decisions in data engineering. This project proves you understand columnar storage, data ingestion pipelines, and query optimization — three pillars of data engineering interviews.

RECRUITER SHORTLIST SIGNAL
----------------------------------------
ClickHouse is the database of choice for real-time analytics at Uber, Cloudflare, and ByteDance. Knowledge of its internals (MergeTree, primary key ordering, compression) is a strong differentiator for Data Engineering roles at scale-up companies.

ARCHITECTURE & DATA FLOW
----------------------------------------
HTTP telemetry ingestion worker queues JSON beacons into Kafka topics. Kafka-ClickHouse engine tables batch write columnar rows into partition-backed MergeTree tables. A GraphQL/REST API queries funnels, retention cohorts, and time-series aggregations in real time.

SCALE & PERFORMANCE TARGETS
----------------------------------------
Ingest 10,000 events/sec while serving 95% of aggregate dashboard queries in < 100ms over 10M+ recorded events.
