PROBLEM STATEMENT
----------------------------------------
Data pipelines silently corrupt downstream analytics when source data quality degrades — wrong schema, null values, outlier ranges, referential integrity violations. Build a data quality framework that automatically validates data contracts, detects anomalies, and blocks bad data from reaching dashboards.

----------------------------------------
Monte Carlo, Great Expectations, and dbt are companies building around this exact problem. Every data team at a mature tech company (Flipkart, Meesho, Swiggy) runs data quality checks. Bad data causes incorrect business decisions that can cost companies millions.

ARCHITECTURE & DATA FLOW
----------------------------------------
dbt models for data transformation with Great Expectations test suites attached. Airflow DAG running quality checks before and after each pipeline stage. Statistical anomaly detection (Z-score, IQR) on numeric columns for out-of-range detection. Alert system with PagerDuty/Slack integration. Quarantine table for failed records.
