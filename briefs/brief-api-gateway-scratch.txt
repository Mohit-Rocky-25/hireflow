PROBLEM STATEMENT
----------------------------------------
Commercial API gateways (Kong, AWS API Gateway) are expensive and opaque. Understanding how they work requires building one. Create a plugin-based API Gateway in Go that handles request routing, load balancing, authentication, rate limiting, request transformation, and health-based failover.

USE CASES IN THE REAL WORLD
----------------------------------------
Every microservices architecture needs an API gateway. Building your own demonstrates understanding of Kong, AWS API Gateway, and Nginx internals. Directly applicable to platform engineering roles at companies running their own infrastructure rather than fully managed cloud services.

WHY THIS IS HARD (COMPETENCY REDUCER)
----------------------------------------
An API Gateway combines reverse proxy, load balancer, authentication server, and plugin runtime into a single system. Building it requires understanding HTTP protocol internals, connection pooling, plugin isolation, and concurrent request handling — a complete systems engineering exercise.

RECRUITER SHORTLIST SIGNAL
----------------------------------------
Kong, Nginx, Envoy, and APISIX knowledge is directly tied to this project. Platform engineers at Cloudflare, FastAPI framework contributors, and any infrastructure team value engineers who understand gateway internals. This is one of the most comprehensive systems projects you can build.

ARCHITECTURE & DATA FLOW
----------------------------------------
Go HTTP reverse proxy with a plugin chain architecture. Each plugin (auth, rate limit, transform, log) implements a common interface and is applied in order. Upstream pool with health checking and weighted round-robin load balancing. Admin REST API for dynamic configuration without restart. Prometheus metrics exporter.

SCALE & PERFORMANCE TARGETS
----------------------------------------
Handle 30,000 req/sec with < 5ms proxy overhead, dynamic plugin configuration with zero-downtime reload, and upstream failover within 2 seconds of health check failure.
