PROJECT BRIEF — Real-Time User Personalization Engine
======================================================================

Domain    : ML Engineering

PROBLEM STATEMENT
----------------------------------------
Generic UI experiences deliver lower conversion rates and higher churn than personalized experiences. Build a real-time personalization engine that learns user preferences from behavioral signals (clicks, dwells, purchases) and serves personalized content rankings within milliseconds.

USE CASES IN THE REAL WORLD
----------------------------------------
Homepage personalization at Flipkart, Myntra, and Swiggy. Content ranking at YouTube, Netflix, and Hotstar. Feed curation at LinkedIn and Twitter. Product recommendation at Amazon. Any company with a content-heavy or product-heavy interface needs personalization.

WHY THIS IS HARD (COMPETENCY REDUCER)
----------------------------------------
Personalization requires combining online learning (real-time behavioral signal updates), precomputed offline user embeddings, and sub-millisecond serving — a technically complex combination. This demonstrates the full ML stack: feature engineering, online learning, model serving, and A/B evaluation.

RECRUITER SHORTLIST SIGNAL
----------------------------------------
Growth engineering, personalization platform, and recommendation systems roles at large consumer companies (Amazon, Flipkart, Netflix India) require exactly this understanding. Online feature updates and real-time scoring are the sophisticated components that separate ML engineers from data scientists.

ARCHITECTURE & DATA FLOW
----------------------------------------
Kafka stream of behavioral events (clicks, impressions, purchases) → Online feature aggregator updating Redis per-user counters in real-time. Offline embedding model computing user/item representations daily. Real-time scoring combining online features with offline embeddings. FastAPI serving with Redis caching. Bandit algorithm for exploration-exploitation.

SCALE & PERFORMANCE TARGETS
----------------------------------------
Update user feature vectors within 500ms of behavioral event, serve personalized rankings for 10M users in < 10ms via Redis, and demonstrate 15%+ CTR improvement over non-personalized baseline in A/B test.
