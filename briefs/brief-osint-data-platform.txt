======================================================================

Domain    : Data Engineering

PROBLEM STATEMENT
----------------------------------------
Businesses manually monitor competitor pricing, job postings, and product changes — a time-consuming and error-prone process. Build a distributed web scraping and intelligence platform that monitors target websites for changes, extracts structured data, and sends real-time alerts on significant changes.

USE CASES IN THE REAL WORLD
----------------------------------------
Competitive price monitoring (Amazon/Flipkart seller tools), job market intelligence (LinkedIn scraping for talent insights), real estate price tracking, stock analyst data gathering, and market research at consulting firms. Companies like SimilarWeb, Semrush, and Bombora are multi-billion-dollar businesses built on this.

WHY THIS IS HARD (COMPETENCY REDUCER)
----------------------------------------
Production web scraping requires handling bot detection, dynamic JavaScript rendering, rate limiting, proxy rotation, and distributed crawl scheduling — significantly harder than simple HTTP requests. This project demonstrates practical distributed systems skills applied to a high-demand business use case.

RECRUITER SHORTLIST SIGNAL
----------------------------------------
Data acquisition and web scraping platforms are used by every data-driven company for competitive intelligence. Scrapy, Playwright, proxy management, and anti-detection techniques are specialized but highly valued skills. Shows you can build data pipelines with real-world constraints.

ARCHITECTURE & DATA FLOW
----------------------------------------
Scrapy-based distributed crawler with Playwright for JavaScript-rendered pages. Redis Bloom filter for URL deduplication across crawler instances. Kafka queue for discovered URLs with priority queuing. PostgreSQL for structured data storage. Change detection using content hashing with diff computation. Email/Slack alerts on detected changes.

SCALE & PERFORMANCE TARGETS
----------------------------------------
Crawl 10,000 pages/hour across 5 target domains with zero-duplicate URL processing, detect content changes within 15 minutes of publication, and extract structured data with 95% accuracy.

SKILLS COVERED
----------------------------------------
Python, Scrapy, PostgreSQL, Kafka, Redis, Data Pipelines

SCREENER VERIFICATION RUBRIC
----------------------------------------
1. JavaScript-rendered page extraction working on React/Vue SPA target sites
2. Deduplication: Bloom filter ensuring each URL crawled exactly once per 24h cycle
3. Change detection: diff between yesterday and today's content with semantic diff
4. Structured data extraction: product name, price, and availability from 3 e-commerce sites
5. Alert notification within 15 minutes of target page content change
