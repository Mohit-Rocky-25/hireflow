PROBLEM STATEMENT
----------------------------------------
Business stakeholders refresh analytics dashboards manually to see current metrics, creating stale data problems. Build a real-time BI dashboard that pushes metric updates via WebSocket as database changes occur, with interactive filtering, drill-down capability, and configurable alert thresholds.

USE CASES IN THE REAL WORLD
----------------------------------------
Operations command centers at top tech platforms, top tech platforms, and OYO; financial dashboards at banks and payment companies; manufacturing quality control dashboards; and healthcare patient monitoring systems all need real-time metrics with push updates.

WHY THIS IS HARD (COMPETENCY REDUCER)
----------------------------------------
Real-time WebSocket-push dashboards require solving backpressure (don't overwhelm slow clients), efficient database change detection (CDC or polling), selective subscription (client only receives updates for displayed metrics), and connection management at scale — a complete full-stack engineering exercise.

ARCHITECTURE & DATA FLOW
----------------------------------------
PostgreSQL trigger or polling service detecting metric changes. Node.js WebSocket server managing subscriptions per metric. React dashboard with Recharts/D3.js for visualization. Client subscribes to specific metric IDs; server pushes updates only for subscribed metrics. Redis pub/sub for broadcasting across multiple WebSocket server instances. Alert threshold configuration with browser notification API.
