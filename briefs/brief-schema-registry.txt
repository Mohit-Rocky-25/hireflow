SCREENER VERIFICATION RUBRIC
----------------------------------------
1. Backward compatibility: new schema version accepted if consumers on old version still work
2. Breaking change rejection: removing required field correctly blocked at registry level
3. Message validation: invalid message rejected before reaching Kafka topic
4. Schema evolution history: full diff between any two versions of same schema
5. Consumer contract test: auto-generated consumer tests verifying message deserialization
