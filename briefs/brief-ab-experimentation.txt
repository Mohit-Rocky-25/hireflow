PROBLEM STATEMENT
----------------------------------------
Traditional frequentist A/B testing requires waiting for statistical significance while causing unnecessary user harm in losing variants. Build a Bayesian experimentation engine that continuously updates posterior probability distributions and allows early stopping when winning variant probability exceeds threshold.

USE CASES IN THE REAL WORLD
----------------------------------------
Booking.com, Netflix, and Etsy run thousands of simultaneous experiments using Bayesian methods. Every product company running A/B tests faces the 'peeking problem' (stopping early when results look good). Bayesian testing solves this principled fashion.

Bayesian A/B testing requires understanding probability theory, conjugate priors (Beta-Binomial for conversion), posterior simulation, and expected loss computation — applied statistics at a production level. ARCHITECTURE & DATA FLOW
----------------------------------------
Beta-Binomial conjugate prior model updated with real-time conversion data. Monte Carlo simulation computing P(A > B) at each event. Expected Loss computation for deciding when to stop. FastAPI backend with PostgreSQL experiment tracking. React dashboard with posterior distribution visualization and stopping recommendation.
