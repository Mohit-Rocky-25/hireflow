PROJECT BRIEF — Layer 7 Load Balancer with Health Checks & Adaptive Routing
======================================================================

Domain    : Distributed Systems

PROBLEM STATEMENT
----------------------------------------
Cloud load balancers are expensive black boxes. Build an L7 (application layer) HTTP load balancer in Go that implements multiple load balancing algorithms (round-robin, weighted, least-connections, IP-hash), active health checks, circuit breaking, and zero-downtime upstream rotation.

USE CASES IN THE REAL WORLD
----------------------------------------
HAProxy, Nginx, and Envoy are all implementations of this. Internal microservices routing, API gateway backends, and custom traffic management scenarios. Any company running self-hosted infrastructure needs load balancing knowledge.

Building one from scratch proves you understand connection pools, health check semantics, graceful draining, and traffic splitting — all topics explicitly discussed in system design interviews at Flipkart, Amazon, and Google.

RECRUITER SHORTLIST SIGNAL
----------------------------------------
Every systems design interview eventually covers load balancers. An engineer who has implemented one can discuss algorithms, health check edge cases, and sticky session trade-offs with authority that interviewers immediately recognize. Unlocks senior backend and platform engineering roles.

ARCHITECTURE & DATA FLOW
----------------------------------------
Go HTTP reverse proxy with pluggable algorithm strategies (round-robin, weighted, least-connections, IP-hash). Background goroutine performs active health checks via GET /health. Unhealthy upstreams removed and re-added upon recovery. Graceful upstream drain: new connections to old upstream blocked while existing ones complete.

SCALE & PERFORMANCE TARGETS
----------------------------------------
Distribute 20,000 req/sec across 5 upstreams with < 3ms overhead, detect unhealthy upstream within 3 health check intervals, and complete traffic drain in < 10 seconds.

SKILLS COVERED
----------------------------------------
Go, Networking, Concurrency, HTTP, System Design, Linux

SCREENER VERIFICATION RUBRIC
----------------------------------------
1. Algorithm test: verify even distribution across 3 upstreams with round-robin
2. Health check test: kill one upstream and verify no requests routed to it within 3s
3. Graceful drain test: in-flight requests complete before upstream removed from pool
4. IP-hash sticky session test: same source IP always routes to same upstream
5. Prometheus metrics showing per-upstream request count and error rate
