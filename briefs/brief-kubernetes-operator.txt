PROJECT BRIEF — Custom Kubernetes Operator with CRD Lifecycle Management
======================================================================

Domain    : Platform & DevOps

Est. Time : 30 hours
Tech Stack: Go, Kubernetes, controller-runtime, Docker, Helm, GitHub Actions

PROBLEM STATEMENT
----------------------------------------
Running stateful applications (databases, message brokers) on Kubernetes requires expert manual management of complex operational tasks like backups, failovers, and schema migrations. Build a custom Kubernetes Operator that automates the full lifecycle of a stateful application using Custom Resource Definitions.

USE CASES IN THE REAL WORLD
----------------------------------------
Every company running databases on Kubernetes needs operators: PostgreSQL Operator, Redis Operator, Kafka Operator, and Elasticsearch Operator are all widely deployed. Cloud providers (AWS, GCP, Azure) run their managed services using operator patterns internally.

WHY THIS IS HARD (COMPETENCY REDUCER)
----------------------------------------
Kubernetes Operators represent the highest level of Kubernetes expertise — understanding of the controller pattern, reconciliation loops, CRD schema design, and Kubernetes API. This separates Kubernetes users from Kubernetes platform engineers, who command 50-100% higher salaries.

RECRUITER SHORTLIST SIGNAL
----------------------------------------
Custom Operator development is a specific skill that only senior platform/SRE engineers possess. Platform teams at Google, Atlassian, and infrastructure companies value this extremely highly. It demonstrates you understand Kubernetes at the control plane level, not just the application deployment level.

ARCHITECTURE & DATA FLOW
----------------------------------------
Go controller using controller-runtime library. Custom Resource Definition (CRD) describing desired state. Reconciliation loop watching for CR changes and reconciling actual vs desired state. Built-in backup CronJob, failover logic on pod failure detection, and rolling upgrade coordination.

SCALE & PERFORMANCE TARGETS
----------------------------------------
Operator reconciles state changes within 10 seconds of CRD update, handles 100+ custom resource instances simultaneously, and completes automated failover within 30 seconds of pod failure.

SKILLS COVERED
----------------------------------------
Go, Kubernetes, Docker, DevOps, Cloud, APIs

SCREENER VERIFICATION RUBRIC
----------------------------------------
1. Working CRD with schema validation and printer column definitions
2. Reconciliation test: delete managed pod and verify operator restores it within 10s
3. Automated backup CronJob created/updated when CRD spec changes
4. Finalizer ensuring clean resource deletion order across all owned objects
5. End-to-end e2e test suite using envtest or KinD (Kubernetes in Docker)
