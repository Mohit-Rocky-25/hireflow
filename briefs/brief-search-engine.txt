PROBLEM STATEMENT
----------------------------------------
Search is foundational to every product yet very few engineers understand how search engines actually work internally. Build a full-text search engine from scratch implementing inverted indexes, TF-IDF ranking, BM25 scoring, and Boolean query operators without using Elasticsearch or Lucene.

USE CASES IN THE REAL WORLD
----------------------------------------
Every website with a search bar is running some variant of this. Internal search (Slack, Notion, Jira), e-commerce product search (Flipkart, Amazon), and document search (Google Docs) all build on these fundamentals. Understanding these internals unlocks contribution to Elasticsearch, Meilisearch, or Typesense.

----------------------------------------

It demonstrates mastery of data structures (inverted index, skip lists), ranking algorithms (TF-IDF, BM25), query planning, and performance optimization — topics that appear in algorithm interviews at every top company.

ARCHITECTURE & DATA FLOW
----------------------------------------
Go implementation with an inverted index stored as a sorted map of term → posting list. Tokenization pipeline (stemming, stop word removal, n-gram generation). BM25 scoring with field weighting. Boolean AND/OR/NOT query parsing. Concurrent indexing with goroutines. HTTP query interface.

SCALE & PERFORMANCE TARGETS
----------------------------------------
Index 1 million documents in under 60 seconds and return top-10 BM25-ranked results for any query in < 30ms.
