### <a id="google-summer-of-code"></a>1. Google Summer of Code

| Specification | Details |
| :--- | :--- |
| **Identifier** | `opp-gsoc` |
| **Issuer / Organizer** | **Google LLC** |
| **Category** | Open Source, Software Development |
| **Kind / Format** | `open_source` |
| **Cost / Fees** | ₹0 FREE · ₹1.65L–₹2.5L Stipend |
| **Official Portal** | [https://summerofcode.withgoogle.com/](https://summerofcode.withgoogle.com/) |
| **Target Engineering Roles** | Backend Developer, Full-Stack Developer, Systems Engineer, AI/ML Engineer |
| **Verified Skills** | Git, GitHub, Open Source Collaboration, C++, Python, Go, Rust, Code Review, CI/CD |

#### 1. Overview & Industry Standing
Google Summer of Code is a premier global open-source program that brings student and beginner developers into open-source software organizations (Apache, Linux Foundation, Python, Mozilla, Chromium). Selected contributors complete a 175-hour or 350-hour engineering project with 1:1 mentorship from veteran maintainers.

#### 2. Core Curriculum & Tested Domains
- **Module 1:** Production open-source architecture in languages like C++, Go, Rust, Python, and TypeScript
- **Module 2:** Git branch workflows, PR etiquette, rebase conflict resolution, and CI/CD pipelines
- **Module 3:** Writing comprehensive unit and integration test suites conforming to repository invariants
- **Module 4:** Distributed systems asynchronous communication and open RFC technical documentation

#### 3. Student Aid & Fee Waiver Playbook
> **Summary:** Google provides monthly living stipends tailored to Indian purchasing power parity (PPP).

**Waiver Claim Steps:**
1. Engage 2-3 months early in chosen open-source organization channels (IRC, Discord, Slack, Zulip).
2. Contribute 2-3 merged pull requests (good-first-issues or test coverage) before proposal deadline.
3. Draft technical design proposal adhering to the organization-specific Google Doc template.
4. Submit official application on the Google Summer of Code portal before the April deadline.

#### 4. Application & Execution Roadmap
1. Explore organizations from previous GSoC cohorts matching your tech stack.
2. Join developer chat channels, introduce yourself, and pick beginner-friendly unresolved issues.
3. Submit clean, well-tested PRs to demonstrate commitment and codebase understanding.
4. Draft a milestone-based project proposal with estimated weekly deliverables and solicit maintainer feedback.
5. Submit final proposal on summerofcode.withgoogle.com before the cutoff timestamp.

#### 5. Exam / Format Details
- **Delivery:** Online, asynchronous remote mentorship
- **Style:** 12-week standard (175h) or 22-week extended (350h) production engineering sprint

#### 6. High-Impact Performative Resume Bullet Formula
```text
"Selected as Google Summer of Code Contributor with [Mentoring Org]; engineered [Feature/Subsystem] using [Tech Stack], merging [X] PRs and reducing [Latency/Memory/Bug Count] by [Metric]."
```

### <a id="smart-india-hackathon"></a>2. Smart India Hackathon

| Specification | Details |
| :--- | :--- |
| **Identifier** | `opp-sih` |
| **Issuer / Organizer** | **Government of India** |
| **Category** | Competitions and Events, Software Development |
| **Kind / Format** | `event` |
| **Cost / Fees** | ₹0 FREE · ₹1,00,000 Prize |
| **Official Portal** | [https://sih.gov.in/](https://sih.gov.in/) |
| **Target Engineering Roles** | Full-Stack Developer, Backend Developer, Mobile Developer, AI/ML Engineer |
| **Verified Skills** | Rapid Prototyping, System Architecture, Full-Stack Engineering, API Integration, Team Leadership, Pitching |

#### 1. Overview & Industry Standing
Smart India Hackathon (SIH) is the world's largest open innovation model launched by the Ministry of Education (MoE), AICTE, and MIC. Over 50,000 collegiate teams compete on real-world challenges submitted by Central Ministries, State Governments, PSUs, and top industries.

#### 2. Core Curriculum & Tested Domains
- **Module 1:** Full-stack software application development or IoT/embedded hardware prototyping
- **Module 2:** API security, encrypted database schemas, and role-based access control (RBAC)
- **Module 3:** Resilient architecture handling rural/offline network conditions and regional languages
- **Module 4:** Live 36-hour continuous sprint under technical jury evaluation from Ministry domain experts

#### 3. Student Aid & Fee Waiver Playbook
> **Summary:** MoE Innovation Cell reimburses train travel allowances and provides food/stay at Nodal Centers.

**Waiver Claim Steps:**
1. Form a mandatory 6-member team with at least 1 female teammate.
2. Pitch your solution at your College Internal Hackathon conducted by your college SPOC.
3. College SPOC nominates top selected teams on the official sih.gov.in portal.
4. Selected finalists travel to designated All-India Nodal Centers for a 36-hour non-stop Grand Finale.

#### 4. Application & Execution Roadmap
1. Study published Problem Statements on sih.gov.in and download technical requirements.
2. Build a functional proof of concept before the internal college hackathon.
3. Win college internal selection (AICTE enforces a cap of nominations per college).
4. Have college Single Point of Contact (SPOC) upload PPT and prototype documentation on SIH portal.
5. Prepare deployment scripts, live demo servers, and pitch deck for national finale.

#### 5. Exam / Format Details
- **Delivery:** Hybrid (Online college nomination + 36h in-person Nodal Center sprint)
- **Style:** 36-hour non-stop hackathon with 3 iterative jury mentoring rounds

#### 6. High-Impact Performative Resume Bullet Formula
```text
"Built [Solution Name], a [Web/Mobile Platform] for [Ministry/PSU Problem Statement] in Smart India Hackathon [Year] using [Tech Stack], responsible for [Architecture/Module], resulting in [Selection/Winner/Finalist]."
```
