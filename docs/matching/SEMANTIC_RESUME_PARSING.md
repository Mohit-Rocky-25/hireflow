# Semantic Resume Parsing & Taxonomy Guidelines

Guidelines for skill extraction, candidate experience normalization, and role hierarchy clustering in HireFlow.

## 1. Skill Taxonomy Graph

- Maps synonymous and derivative technical proficiencies into canonical taxonomy nodes (e.g., `React.js`, `React`, `React Native` -> `Frontend: React Ecosystem`).
- Experience weight calibration distinguishes between primary production responsibilities vs peripheral coursework mentions.

## 2. Normalization Engine

- Standardizes irregular date formats and tenure calculations across diverse international CV templates.
- Extracts structured metrics (e.g., latency improvements, revenue scale, team size) into quantifiable achievement records.
