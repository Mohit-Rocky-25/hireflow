# HireFlow Tailor Engine — Defect Resolution Changelog

This changelog maps each of the 8 known defects to its architectural remediation across the 7-stage pipeline.

| Defect # | Reported Issue | Root Cause | Architectural Fix | Files Changed |
|---|---|---|---|---|
| **Defect 1** | Projects/experience text flattened into Skills as one comma-joined paragraph (`...APK., Identified...`) | Compound project headings were unrecognized, spilling project blocks into skills where `CATEGORY_MAP` default dumped sentences into `Core Competencies` joined by commas. | Added Stage 3 deterministic block router (`routeResumeContent`) with strict sentence rerouting. Skills are restricted to atomic tokens (max 6 words, no action verbs). Project titles and action verbs are cleanly routed to `projects[].bullets`. | `engine/route/index.ts`, `engine/schema.ts`, `structure/skillsParser.ts`, `structure/projectsParser.ts` |
| **Defect 2** | Summary renders in a serif font and is justified; everything else is sans-serif and left-aligned. | Root template container had `font-serif` and `renderSummary` applied `text-justify`. | Unified all typography in `tokens.ts` to single sans-serif family (`Inter, system-ui`). Removed `text-justify` and `font-serif` across `ClassicTemplate.tsx` in favor of uniform `text-left font-sans`. | `engine/tokens.ts`, `templates/ClassicTemplate.tsx` |
| **Defect 3** | Categories with a single item appear as orphan lines instead of being merged. | Parser created 1-item micro-groups for unmapped categories. | In Stage 3 ROUTE, `mergeSkillGroups` merges any group with fewer than 2 items into the nearest category. Target is 3–5 balanced groups. Template rendering also merges orphans. | `engine/route/index.ts`, `templates/ClassicTemplate.tsx` |
| **Defect 4** | A bullet starts lowercase and is a sentence fragment. | Raw input bullets from informal resumes were not capitalized or normalized. | In Stage 4 POLISH, `polishBullet` capitalizes initial letters (`charAt(0).toUpperCase()`), strips leading dashes/symbols, strips stray trailing punctuation, and ensures uniform ending period. | `engine/polish/index.ts` |
| **Defect 5** | Education has no dates or grade fields. | Education parser dropped dates on dashed single-line formats (`2018 - 2022`). | Expanded Stage 3 `parseEducationChunk` to support pipe, dash, and multi-line dates/GPA. In Stage 6 VALIDATE, missing dates produce non-blocking suggestions rather than fabricated dates. | `engine/route/index.ts`, `engine/validate/index.ts` |
| **Defect 6** | Contact line wraps badly, leaving `github.com/...` alone on line two. | Raw paragraph joined all links with ` \| ` without checking line wrapping balance. | Added `balanceContactLine` in Stage 5 LAYOUT. If contact items exceed 4, they are split evenly across 2 balanced lines, preventing orphan links. | `engine/layout/index.ts`, `templates/ClassicTemplate.tsx` |
| **Defect 7** | Large blank area at bottom of page; no page-fit logic. | Fixed template height without measurement or spacing adjustments. | Implemented dynamic Page-Fit iterative loop in Stage 5 LAYOUT (`buildLayoutTree`). Measures line density against 48-line page capacity, dynamically adjusting section spacing (10pt -> 6pt) and body font (10pt -> 9.5pt) to optimize fit. | `engine/layout/index.ts` |
| **Defect 8** | Certifications mix completed, in-progress, and self-study items without labels. | Certifications were raw strings without typed status metadata. | Defined `CertificationItemSchema` in Zod with strictly typed `status: 'completed' \| 'in_progress' \| 'coursework'`. Parser classifies coursework and in-progress items, displaying clear labels. | `engine/schema.ts`, `engine/route/index.ts`, `engine/layout/index.ts` |
