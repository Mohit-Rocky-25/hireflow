# HireFlow Tailor Engine — Defect Resolution Changelog

This changelog records the complete architectural remediations across the HireFlow 7-stage resume engine pipeline adhering to Non-Negotiable Rules R1–R5 (zero loss, zero fabrication, deterministic execution).

## Defect Matrix & Architectural Remediation

| Defect # | Component / Stage | Reported Issue | Root Cause | Architectural Fix | Files Changed & Tests |
|---|---|---|---|---|---|
| **Defect 1** | Stage 3 (ROUTE) | Projects/experience text flattened into Skills as one comma-joined paragraph (`...APK., Identified...`) | Compound project headings were unrecognized, spilling project blocks into skills where `CATEGORY_MAP` default dumped sentences into `Core Competencies` joined by commas. | Added Stage 3 deterministic block router (`routeResumeContent`) with strict sentence rerouting. Skills are restricted to atomic tokens (max 6 words, no action verbs). Project titles and action verbs are cleanly routed to `projects[].bullets`. | `engine/route/index.ts`, `engine/schema.ts`, `structure/skillsParser.ts`, `structure/projectsParser.ts`<br>*(Test: `regression.test.ts`)* |
| **Defect 2** | Stage 7 (RENDER) | Summary renders in a serif font and is justified; everything else is sans-serif and left-aligned. | Root template container had `font-serif` and `renderSummary` applied `text-justify`. | Unified all typography in `tokens.ts` to single sans-serif family (`Inter, system-ui`). Removed `text-justify` and `font-serif` across `ClassicTemplate.tsx` in favor of uniform `text-left font-sans`. | `engine/tokens.ts`, `templates/ClassicTemplate.tsx`<br>*(Test: `typography.test.ts`)* |
| **Defect 3** | Stage 3 (ROUTE) | Categories with a single item appear as orphan lines instead of being merged. | Parser created 1-item micro-groups for unmapped categories. | In Stage 3 ROUTE, `mergeSkillGroups` merges any group with fewer than 2 items into the nearest category. Target is 3–5 balanced groups. Template rendering also merges orphans. | `engine/route/index.ts`, `templates/ClassicTemplate.tsx`<br>*(Test: `stage3-engine-review.test.ts`)* |
| **Defect 4** | Stage 3 & 4 (ROUTE / POLISH) | Bullet splitting bug: Lowercase fragment (`maintains a public, day-by-day cybersecurity learning log.`) produced as standalone bullet. | Naive line-break and punctuation splitting treated subordinate clauses beginning with lowercase or lacking subject/verb as new bullets. | Updated `splitIntoBullets` in `engine/route/index.ts`: Any line starting lowercase or lacking an independent subject/verb is merged back into the preceding bullet. Fragments that cannot be merged are routed to `needs_review`. Added property test asserting zero bullets start lowercase across all fixtures. | `engine/route/index.ts`, `engine/polish/index.ts`<br>*(Test: `bullet-splitter.test.ts`)* |
| **Defect 5** | Stage 5 & 6 (LAYOUT / VALIDATE) | Education completeness: Missing start/end/expected/gpa; templates lacked canonical formatting. | Parsers either dropped dates or templates did not provide user actions to fill missing fields without fabrication. | Enforced R4 Zero-Fabrication: If start/end/expected/gpa are missing, `validateResume` emits an ATS lint warning and a Suggestions entry with `fixAction: { type: 'open_input_fields', fields: [...] }`. Canonical pipe rendering: `"B.Tech in ECE \| VIT-AP University \| 2024 - 2028 (Expected) \| CGPA: x.xx"`. | `engine/validate/index.ts`, `templates/ClassicTemplate.tsx`<br>*(Test: `education-completeness.test.ts`)* |
| **Defect 6** | Stage 5 (LAYOUT) | Contact line wraps badly, leaving `github.com/...` alone on line two. | Raw paragraph joined all links with ` \| ` without checking line wrapping balance. | Added `balanceContactLine` in Stage 5 LAYOUT. If contact items exceed 4, they are split evenly across 2 balanced lines, preventing orphan links. | `engine/layout/index.ts`, `templates/ClassicTemplate.tsx`<br>*(Test: `header-overlap.test.ts`)* |
| **Defect 7** | Stage 5 (LAYOUT) | Large blank area at bottom of page; no page-fit logic. | Fixed template height without measurement or spacing adjustments. | Implemented dynamic Page-Fit iterative loop in Stage 5 LAYOUT (`buildLayoutTree`). Measures line density against 48-line page capacity, dynamically adjusting section spacing (10pt -> 6pt) and body font (10pt -> 9.5pt) to optimize fit. | `engine/layout/index.ts`<br>*(Test: `page-fit.test.ts`)* |
| **Defect 8** | Stage 3 & 5 (ROUTE / LAYOUT) | Certifications mix completed, in-progress, and self-study items without labels. | Certifications were unstructured raw strings without status segregation. | Split section into labeled groups using `certification.status`: `"Completed"`, `"In Progress"`, and `"Self-Directed Practice"`. Renamed section heading to `"CERTIFICATIONS & LEARNING"`. Mixed statuses are never combined in a single bullet. | `engine/schema.ts`, `engine/route/index.ts`, `templates/ClassicTemplate.tsx`<br>*(Test: `certifications-split.test.ts`)* |
| **Defect 9 (New)** | Stage 2 & 3 (PARSE / SCHEMA) | Date/Stack Field Leak: Project rendered date slot as `"2026, JADX"`. | Loose date parsing regex captured subsequent stack tool tokens into the date field. | Added Zod refinement on `DateFieldSchema` rejecting any known tool tokens (`JADX`, `APKTool`, `Ghidra`, `Burp Suite`, `Docker`, etc.). Tools are cleanly extracted to `project.stack[]` and rendered on their own line as `"Tools: JADX, APKTool"`. | `engine/schema.ts`, `engine/route/index.ts`, `templates/ClassicTemplate.tsx`<br>*(Test: `date-stack.test.ts`)* |
| **Defect 10 (New)** | Stage 3 & 7 (ROUTE / RENDER) | Routing: Competitions & CTFs misrouted to Projects (`L3AK CTF 2026`). | Routing patterns did not classify CTF/hackathon blocks into achievements. | Block router routes any block containing `contest`, `ctf`, `competition`, `hackathon`, `rank`, `award`, or `winner` to `achievements` with confidence >= 0.8. Rendered as dedicated `"ACHIEVEMENTS"` section positioned between Projects and Leadership. | `engine/route/index.ts`, `engine/schema.ts`, `templates/ClassicTemplate.tsx`, `recoveryEngine.ts`<br>*(Test: `competition-routing.test.ts`)* |
| **Polish A** | Stage 4 (POLISH) | Professional Summary Trimming & Role Targeting. | Verbose summaries exceeded recruiter attention limits and contained generic seeking statements. | Implemented `trimProfessionalSummary`: strictly enforces max 60 words and max 3 lines/sentences via deterministic scoring (dropping weakest sentence). Replaces generic seeking clause with specific role if `targetRole` provided (`"Seeking a Mobile Application Security Intern role"`), or drops it if omitted. Exposes `summaryDiff: { original, trimmed }`. | `engine/polish/index.ts`<br>*(Test: `summary-trim.test.ts`)* |
| **Polish B** | Stage 4 (POLISH) | Tense Normalization by Date Range. | Inconsistent mixing of past and present verbs across ongoing vs completed experiences. | Deterministic `normalizeVerbTense` backed by 50+ action verb lexicon: converts verbs to present tense if end date is `"Present"`, and past tense for completed dates. | `engine/polish/index.ts`<br>*(Test: `verb-tense.test.ts`)* |
| **Defect 11 (Redesign)** | Stage 4 & UI (SUGGESTIONS / SAFETY) | Suggestions redesigned: SAFE_EDIT vs QUESTION. Removed fabricated claims, canned patterns and JD injection. Added export gate and honest scoring. | Non-expert users could not distinguish authentic source improvements from fabricated claims (`tested across [25] test cases`, `zero packet drop`) or missing JD keywords injected as 1-click additions. | Partitioned all suggestions into two strict classes: `SAFE_EDIT` (source tokens only, before/after word diff, 1-click Accept, Undo) and `QUESTION` (plain-language question, empty input, user supplies facts, NO 1-click Accept until typed). Removed all canned claims and bracket placeholders `[ ]`. Missing JD keywords create interview-safe questions requiring evidence. Implemented recruiter safety export gate (blocking export on placeholders or unverified claims; pre-export verification screen with confirmation checkboxes for user-added lines). Replaced artificial score boosts with honest keyword match scoring. | `src/lib/tailorEngine/engine.ts`, `src/lib/tailorEngine/parser.ts`, `src/lib/tailorEngine/actionWordEngine.ts`, `src/features/suite/tailor/components/SuggestionCard.tsx`, `src/features/suite/tailor/components/ExportTruthGateModal.tsx`, `src/features/suite/tailor/components/ReviewTabBar.tsx`, `src/features/suite/tailor/components/templates/ClassicTemplate.tsx`, `src/features/suite/tailor/TailorResumePage.tsx`<br>*(Tests: `safe-suggestions-redesign.test.ts`, `cybersecurity-tailor-flow.test.ts`)* |
