# Reach Out (Cold Outreach Generator) — Empirical Baseline Report (Stage 0)

## 1. Overview
This report provides the quantitative baseline for Reach Out generated by running the existing engine across 30 diverse, realistic candidate profiles and all 50 existing templates (1,500 total outputs).

## 3. Profiles Tested in Simulation

The 30 test candidate profiles evaluated in Stage 0.3 included:
1. **Long Names**: `Suryanarayana Venkateshwarlu` (28 chars), `Padmanabhan Ramakrishnan` (24 chars).
2. **Diacritics**: `René François`, `Zoë Ní Chonaill`, `Pranäv Sharmä`.
3. **Indic Scripts**: `आरव शर्मा` (Devanagari), `राहुल वर्मा`.
4. **Initials & Honorifics**: `K. V. S. R. Murthy`, `Dr. Vikram Sen`.
5. **Vowel-Initial Roles**: `SDE Intern` (needs "an"), `ML Intern` (needs "an"), `AI Researcher` (needs "an"), `UI Engineer` (needs "a"), `Operations Analyst` (needs "an").
6. **Extreme Proof Points**: Long multi-metric bullet (212 characters), short proof points, and missing proof points.
7. **Sparse Profiles**: Missing optional fields (college, proof, portfolio link).

## 4. Root Causes of As-Is Defects

1. **Unmapped Template Slots**: Templates added to `outreach-templates.json` introduced new slot names (`job_id`, `event_name`, `talk_topic`, `notice_period`, etc.) that were never registered in `fillSlots` or `DEFAULT_SLOT_PLACEHOLDERS`.
2. **Missing Length Adaptation Engine**: The current generator performs simple string replacement without trimming, prioritizing, or dropping optional clauses when character ceilings are exceeded.
3. **Absence of Sound-Based Grammar**: String interpolation assumes "a" before roles, resulting in phonetically broken English like "a SDE" and "a ML intern".
4. **Outdated Platform Assumptions**: The codebase assumed all LinkedIn connection notes have a 300-character ceiling, ignoring the 200-character limit on standard free accounts.
