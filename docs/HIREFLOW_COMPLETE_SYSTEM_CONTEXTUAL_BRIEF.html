1. Executive Overview & Platform Philosophy

HireFlow is an advanced, client-side engineering intelligence platform designed to empower job seekers—from 2nd-to-final year Indian engineering students to senior staff engineers—with deterministic, truth-checked career diagnostics and simulations.

Core Architectural Axioms

1. Zero Runtime Network Egress: User resumes, JDs, compensation numbers, and profile details are evaluated entirely inside the browser. No telemetry or tracking SDKs exist. 2. Deterministic Invariant Scoring: Scores are not random LLM guesses. They are calculated using pure, mathematical formulas with strict invariant properties (e.g. scores always strictly in range [0, 100], zero score without matching skills, predictable subscore derivations). 3. No-Hallucination Rewriting (Truth Gate): The system strictly prevents AI from fabricating achievements. An original bullet stating "assisted with database testing" can never be rewritten to claim "architected distributed PostgreSQL clusters". 4. India Market Calibration: All compensation calculations, tax computations, service bond evaluations, college placement tiers, and career progression models are tailored to Indian engineering realities (INR Lakhs per Annum / LPA, New Regime FY 26–27 income tax, EPFO statutory ceilings, Section 74 service bonds).

3. Deep-Dive into the 9 Subsystems

3.1 ATS Resume Roaster & Invariant Scorer

  • Path: src/lib/ats/, src/pages/tools/ResumeChecker.tsx
  • Core Problem Solved: Eliminates opaque, subjective resume reviews with transparent, deterministic scoring.
  • The Four Evaluation Pillars:
1. Hard Skill Requirement Coverage (40%): - Evaluates mandatory vs. preferred skills extracted from the JD. - Direct matches earn 1.0 credit; transferable skills (via implication-graph.json) earn 0.7 credit; partial mentions earn 0.4 credit. 2. Evidence Quality & Bullet Impact (25%): - Audits every bullet against Google's XYZ formula: "Accomplished [X], as measured by [Y], by doing [Z]". - Uses writing-quality.json to credit decisive action verbs and penalize passive/weak language. 3. Fresher / Project Readiness (20%): - Evaluates verified project deliverables, GitHub repositories, competitive programming links, and technical coursework. 4. Format & Parser Safety (15%): - Audits layout against multi-column tables, floating text boxes, graphic icons, non-standard section headers, and font anomalies.
  • Penalty Penalties:
- Keyword stuffing: -10 points deducted if $>60\%$ of listed skills lack bullet evidence. - Missing standard sections: -3 points per section. - Abnormally sparse resume: -4 points.
  • Invariant Guarantees:
- Score $\in [0, 100]$ strictly. - If zero mandatory skills match, final score cannot exceed 35. - Deterministic: identical inputs generate identical scores down to the decimal.

3.2 Tailor My Resume Diff Engine

  • Path: src/features/suite/tailor/, src/engine/tailor/
  • Core Problem Solved: Allows candidates to align their resume to a specific JD without fabricating qualifications.
  • Key Modules:
- Layout Tree Parser: Deconstructs raw resume text into semantic blocks (Header, Experience, Projects, Education, Skills). - The Truth Gate (truthGate.ts): Evaluates rewrites using the 4-tier Claim Strength Ladder: - Tier 1 (Supportive): assisted, helped, supported, participated - Tier 2 (Contributory): contributed, worked, collaborated, maintained - Tier 3 (Direct Execution): built, created, developed, implemented, designed - Tier 4 (Leadership / Architecture): architected, spearheaded, orchestrated, led - Rule: A rewrite may never elevate a verb by more than one tier without explicit project evidence. - Required Metric Placeholders: Leaves highlighted tags like [X]% latency reduction for the user to substitute real metrics.

3.3 Reach Out Cold Outreach Generator

  • Path: src/features/suite/outreach/
  • Core Problem Solved: Replaces awkward, generic messages with context-aware, verifiable cold emails and connection notes.
  • Key Capabilities:
- LinkedIn 300-Char Mode: Strict character-counter ensuring messages fit LinkedIn connection request constraints. - Channel Modes: InMail, Cold Email, Alumni Network, Recruiter Follow-up. - Proof-Point Integration: Automatically weaves candidate's strongest verified metric or project into the hook. - Spam Word Filter: Flags high-risk words ("urgent", "guarantee", "pleased to inform") that trigger spam quarantine.

3.4 Project Build Briefs Engine

  • Path: src/features/suite/briefs/, src/data/suite/project-briefs.json
  • Core Problem Solved: Tells candidates exactly what to build to close their specific resume gaps.
  • How It Works:
- Identifies missing skills from the ATS scan. - Matches gaps to production engineering project briefs. - Each brief includes: 1. System Architecture & Component Diagram 2. Real-World Scale Targets (e.g., 10k concurrent WebSockets, <50ms p99 latency) 3. Mandatory Deliverables (Docker Compose, CI/CD pipeline, integration tests) 4. Verification Rubric (How to prove it works on GitHub) 5. Interview Defense Guide (Anticipated technical questions and failure modes)

3.5 Credential & Opportunity Engine

  • Path: src/features/suite/credentials/
  • Core Problem Solved: Maps verified, high-ROI credentials and national competitions for Indian engineering students.
  • Opportunity Catalog:
- National Competitions: Smart India Hackathon (SIH), Flipkart GRiD, Tata Crucible, Amazon ML Challenge. - Global Fellowships: Google Summer of Code (GSoC), Linux Foundation Mentorship (LFX), MLH Fellowship. - Industry Certifications: AWS Certified Developer, CKA (Certified Kubernetes Administrator), Meta Frontend/Backend.
  • Eligibility Engine: Filters by university year, degree (B.Tech, B.E., MCA), branch, and fee waiver eligibility.

3.6 Career Trajectory & Company Ladders

  • Path: src/careers-core/, src/data/careerLadders/, src/pages/tools/career-path/
  • Core Problem Solved: Models progression ladders, salary growth, and promotion stall rates across 56+ Indian employers.
  • Tiers & Down-Leveling Rules:
- Tier S: FAANG, Uber, HFTs (CTC ₹35L–₹1.2Cr+) - Tier A: High-Growth Unicorns (Swiggy, Razorpay, Cred; CTC ₹22L–₹50L) - Tier B: Product & Established Fintech (Paytm, Zoho, MakeMyTrip; CTC ₹12L–₹28L) - Tier C: IT Services & Consulting (TCS, Infosys, Cognizant; CTC ₹3.6L–₹12L) - Down-Leveling Factor: When moving from Tier C to Tier S, candidates face an average 1–2 level down-leveling discount due to architectural depth expectations.

3.7 Compare Job Descriptions Engine

  • Path: src/features/suite/compare/
  • Core Problem Solved: Evaluates multiple job offers or descriptions side-by-side to prioritize application efforts.
  • Outputs:
- Shared skill intersections across JDs. - Unique technical requirements per company. - Coverage Yield: Calculates which target JD offers the greatest marginal return for the candidate's existing skillset.

3.8 TalentLens Diagnostic Engine

  • Path: src/pages/tools/TalentLens.tsx, src/data/ats/archetypes.json
  • Core Problem Solved: Comprehensive candidate diagnostic benchmark.
  • The 6 Core Technical Archetypes:
1. Systems Architect: Distributed systems, concurrency, cloud infrastructure, latency optimization. 2. Full-Stack Builder: End-to-end web apps, API design, relational databases, state management. 3. Data & ML Specialist: Python, PyTorch, SQL, data pipelines, model serving. 4. Cloud & DevOps Specialist: Kubernetes, Terraform, CI/CD, observability, Linux internals. 5. Frontend Specialist: React, performance optimization, accessibility, component systems. 6. Quality & Reliability Engineer: Automation frameworks, load testing, chaos engineering.

3.9 Pathways Fresher Campus Intelligence Suite

  • Path: src/pathways/
  • Core Problem Solved: Replaces outdated career trajectory tools for Indian freshers with verified campus data.
  • Five Key Modules:
1. Eligibility Radar (/tools/pathways): Instant 3-input evaluation (Branch, Batch, CGPA) against 20 verified programs. 2. CGPA Gap Calculator: Pure formula: $$R = \frac{T \cdot N - C \cdot n}{N - n}$$ Calculates required GPA in remaining semesters with equal-credit caveat. 3. Offer Evaluator (/tools/pathways/offers): - Decomposes CTC into Gross Cash vs. Employer Provisions (PF, Gratuity, Insurance). - 3 monthly scenarios (100%, 50%, 0% variable payout). - New Regime FY 26–27 income tax calculation with ₹75,000 standard deduction and ₹12,00,000 Section 87A rebate. - Month 0–36 Exit Exposure Timeline (Service Bond + Bonus Clawback). 4. Action Plan (/tools/pathways/plan): Prioritized 3-lane roadmap (Blockers $\to$ Readiness Gaps $\to$ Process Prep). 5. Data & Methodology (/tools/pathways/about-data): Open provenance ledger with SHA-256 integrity proofs.

/
  Detects the nearest branch family from custom user input.
 /
export function detectBranchFamily(input: string): BranchFamily {
  const norm = input.trim().toLowerCase();

  // Mechanical / Automobile / Robotics
  if (
    norm.includes('mech') ||
    norm.includes('auto') ||
    norm.includes('robot') ||
    norm.includes('aero') ||
    norm.includes('manufacturing') ||
    norm.includes('production') ||
    norm.includes('metallurg') ||
    norm.includes('thermal') ||
    norm.includes('cad') ||
    norm.includes('cae')
  ) {
    return 'core-mechanical';
  }

  // Civil & Infrastructure
  if (
    norm.includes('civil') ||
    norm.includes('struct') ||
    norm.includes('construct') ||
    norm.includes('mining') ||
    norm.includes('geotech') ||
    norm.includes('survey')
  ) {
    return 'core-civil';
  }

  // Chemical, Biotech & Agriculture
  if (
    norm.includes('chem') ||
    norm.includes('bio') ||
    norm.includes('agri') ||
    norm.includes('food') ||
    norm.includes('pharm') ||
    norm.includes('environmental')
  ) {
    return 'chemical-bio';
  }

  // Electronics & Embedded
  if (
    norm.includes('electr') ||
    norm.includes('ece') ||
    norm.includes('eee') ||
    norm.includes('vlsi') ||
    norm.includes('embedded') ||
    norm.includes('iot') ||
    norm.includes('sensor') ||
    norm.includes('instrument') ||
    norm.includes('telecom')
  ) {
    return 'electronics-embedded';
  }

  // Data & AI
  if (
    norm.includes('data') ||
    norm.includes('ai') ||
    norm.includes('ml') ||
    norm.includes('machine learning') ||
    norm.includes('artificial') ||
    norm.includes('stat') ||
    norm.includes('analytics')
  ) {
    return 'data-ai';
  }

  // Management & Business
  if (
    norm.includes('mba') ||
    norm.includes('bba') ||
    norm.includes('manage') ||
    norm.includes('business') ||
    norm.includes('finance') ||
    norm.includes('market') ||
    norm.includes('product')
  ) {
    return 'management';
  }

  // Default to Software
  return 'software';
}

/
  Returns grouped list of degrees and branches for combobox display.
 /
export function getGroupedDegreeOptions(): Record<string, DegreeBranchOption[]> {
  const groups: Record<string, DegreeBranchOption[]> = {
    'B.Tech / B.E': [],
    'Integrated / Dual Degree': [],
    'UG Others': [],
    'PG (Postgraduate)': [],
  };

  DEGREE_BRANCH_CATALOG.forEach((item) => {
    if (groups[item.degreeGroup]) {
      groups[item.degreeGroup].push(item);
    }
  });

  return groups;
}

/
  Resolves a degree/branch option by id or returns custom option for custom input.
 */
export function resolveDegreeBranchOption(value: string): DegreeBranchOption {
  const found = DEGREE_BRANCH_CATALOG.find((o) => o.id === value || o.label === value || o.branchName === value);
  if (found) return found;

  // Custom user input
  const family = detectBranchFamily(value);
  const isPg = value.toLowerCase().includes('m.tech') || value.toLowerCase().includes('mca') || value.toLowerCase().includes('mba') || value.toLowerCase().includes('m.sc');
  const isDual = value.toLowerCase().includes('dual') || value.toLowerCase().includes('integrated') || value.toLowerCase().includes('arch');
  const isUg3 = value.toLowerCase().includes('bca') || value.toLowerCase().includes('b.sc') || value.toLowerCase().includes('bba');
  const programLength = isDual ? 5 : isPg ? 2 : isUg3 ? 3 : 4;

  return {
    id: 'custom-other',
    degreeGroup: isDual ? 'Integrated / Dual Degree' : isPg ? 'PG (Postgraduate)' : isUg3 ? 'UG Others' : 'B.Tech / B.E',
    degreeName: value,
    branchName: value,
    family,
    familyLabel: BRANCH_FAMILY_LABELS[family],
    programLength,
    label: value,
  };
}
