1. Project Build Briefs Catalog (158 Briefs)

The catalog is located at src/data/suite/project-briefs.json (831.8 KB) spanning 26 engineering domains.

Minor Content Flaws

  • Minor Overlapping Domain Taxonomies: Taxonomies feature confusing duplicates (e.g. Cloud Architecture & DevOps vs Cloud Native & DevOps Engineering vs Platform & DevOps).
  • Minor Superficial Recruiter Signals: Standard briefs promise "Signals mastery of web scalability", which is a generic cliché rejected by senior hiring managers.

Moderate Content Flaws

  • Moderate Heavy Low-Level Systems Bias: Over 65% of briefs center on low-level systems (Kernel FUSE, Raft in Rust, Epoll C event loops). Yet 85% of real Indian campus hiring is for standard Full-Stack, Spring Boot microservices, or Data Engineering.
  • Moderate Missing Code Starters & Scaffolding: Briefs explain what to build but lack starter repositories, test fixtures, and debugging guides when students hit dead ends.

Major Content Flaws

  • Major Grossly Underestimated Time Budgets (Avg: 27.2 Hours):
    Ground Reality: Building a production-grade Bayesian A/B Experimentation Engine or a lock-free distributed cache in 29 hours is mathematically impossible for an engineering student. Real-world completion requires 80 to 120 hours. Advertising 27 hours drives student anxiety and encourages plagiarizing existing GitHub repos.

  • High 100% Synthetic Job Descriptions: 100% of roles are marked profileKind: 'representative' generated via Claude batch prompts, lacking real company framework nuances and team contexts.
  • High Static Salary Bands Ignoring College Tiers: Ignores the colossal gap where Tier-1 on-campus hiring (IIT/NIT/BITS) pays 44 LPA vs off-campus hiring drives paying 16–22 LPA for the exact same job title.

3. ATS Resume Roaster

Located at src/lib/ats/ and src/features/ats/engine/.

Key Flaws & Remediation

  • High Keyword Density Vulnerability: Evaluates resumes on token boundary matches rather than semantic contextual depth. Keyword lists score high without deep implementation evidence.
  • Moderate Outdated ATS Formatting Dogma: Strictly penalizes modern 2-column resumes, despite modern ATS (Greenhouse, Lever, Ashby 2024+) parsing 2-column PDFs with zero OCR loss.
  • Moderate Parallel Engine Divergence: Two parallel engines exist (src/lib/ats/ vs src/features/ats/engine/), creating ongoing code duplication and drift risks.

4. Tailor My Resume

Located at src/features/suite/tailor/ and src/lib/resume/.

Key Flaws & Remediation

  • High Deterministic Verb Rewriting Lacks Generative Nuance: Strict Zero-Egress rule prevents LLM generation, leaving bullet rewriting to rule-based verb swapping that can sound robotic.
  • Moderate Aggressive 1-Page Clamp: Clamping all resumes to 1 A4 page causes unreadable visual overcrowding for multi-internship candidates.
  • High Multi-Column Text Interleaving: Standard PDF.js text extraction reads across columns horizontally, scrambling two-column resumes.

5. Reach Out (Cold Outreach)

Located at src/features/suite/outreach/ (85 Templates).

Key Flaws & Remediation

  • High Misalignment with Indian Tech Ecosystem: Western cold outbound has a < 2% response rate in India. Candidates succeed via 1st-degree alumni referrals and warm introductions, which the tool currently lacks.
  • Moderate Rigid Metric Slot Demands: Forcing a {{metric_result}} blocks freshers whose academic capstones lack production traffic or measured dollar savings.
  • Moderate LinkedIn 200c Free Limit Bottleneck: Fitting Hook + Proof + Ask into 200 characters leaves zero space for genuine personalization once Indian names are inserted.
