# Design System Typography & Responsive Layout Tokens

Design tokens defining typography hierarchies, fluid scaling formulas, and grid geometry across HireFlow.

## 1. Type Scale Tokens

- `font-size-xs`: `0.75rem` (12px)
- `font-size-sm`: `0.875rem` (14px)
- `font-size-base`: `1.000rem` (16px)
- `font-size-lg`: `1.125rem` (18px)
- `font-size-xl`: `1.250rem` (20px)
- `font-size-2xl`: `1.500rem` (24px)
- `font-size-3xl`: `1.875rem` (30px)

## 2. Responsive Breakpoint Tokens

- `bp-sm`: `640px` (Compact mobile / small tablets)
- `bp-md`: `768px` (Tablets / portrait view)
- `bp-lg`: `1024px` (Laptop / desktop viewports)
- `bp-xl`: `1280px` (Wide desktop displays)
