# Anonymized Real Calibration Data

This directory is reserved for real candidate evaluation pairs for calibration against actual hiring decisions.

## Anonymization Protocol (Required Before Adding Any Real Resume)
Under HireFlow Principle P-1 (Privacy & Non-Fabrication):
1. **Remove all Personal Identifiable Information (PII)**:
   - Full legal names replaced with synthetic pseudonyms (e.g. `Candidate A`).
   - Phone numbers, email addresses, home addresses, and postal codes removed.
   - College roll numbers, registration numbers, and government ID numbers stripped.
2. **Replace URLs**:
   - Replace private LinkedIn handles with `linkedin.com/in/anonymized`.
   - Remove private company names or internal project links where confidentiality applies.
3. **Commit Restrictions**:
   - This directory `data/calibration/real/` is permanently gitignored.
   - Never commit raw un-anonymized candidate resumes to public or private git repositories.
