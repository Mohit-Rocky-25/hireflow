PROBLEM STATEMENT
----------------------------------------
Cloud load balancers are expensive black boxes. Build an L7 (application layer) HTTP load balancer in Go that implements multiple load balancing algorithms (round-robin, weighted, least-connections, IP-hash), active health checks, circuit breaking, and zero-downtime upstream rotation.

ARCHITECTURE & DATA FLOW
----------------------------------------
Go HTTP reverse proxy with pluggable algorithm strategies (round-robin, weighted, least-connections, IP-hash). Background goroutine performs active health checks via GET /health. Unhealthy upstreams removed and re-added upon recovery. Graceful upstream drain: new connections to old upstream blocked while existing ones complete.
