PROBLEM STATEMENT
----------------------------------------
Database administrators with access to production databases can read all user data. Homomorphic Encryption (HE) allows computations on encrypted data without decryption. Build a prototype system demonstrating encrypted database aggregations (SUM, AVG) where the database server never sees plaintext values.

USE CASES IN THE REAL WORLD
----------------------------------------
Healthcare data analytics (compute statistics over encrypted patient data), financial regulators (audit bank data without seeing individual transactions), cloud database providers offering confidential computing, and privacy-preserving ML training on sensitive datasets.
