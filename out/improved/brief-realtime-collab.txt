PROBLEM STATEMENT
----------------------------------------
Concurrent document editors suffer from conflict desynchronization and high latency over lossy networks. When two users edit the same line simultaneously, naive approaches lose one edit entirely. Build a zero-conflict collaborative whiteboard or markdown editor where remote edits seamlessly converge using Conflict-free Replicated Data Types (CRDTs).

USE CASES IN THE REAL WORLD
----------------------------------------
Notion, Figma, distributed systems platforms Docs, and Miro all solve this exact problem at scale. In the Indian market, startups like Springworks and Leena AI are building collaborative HR tools that need sub-second sync. Any B2B SaaS product with collaboration features faces this challenge.
