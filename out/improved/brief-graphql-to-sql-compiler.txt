PROBLEM STATEMENT
----------------------------------------
GraphQL resolvers with naive database access produce catastrophic N+1 query patterns that can execute 1000+ SQL queries for a single API request. Build a GraphQL-to-SQL compiler that analyzes incoming GraphQL queries and generates a single optimized SQL query using JOIN inference.

USE CASES IN THE REAL WORLD
----------------------------------------
Hasura, PostGraphile, and Prisma all solve this at scale. Any company building a data-intensive GraphQL API needs query optimization. Understanding this unlocks contributions to ORM internals, GraphQL framework development, and backend query optimization.

WHY THIS IS HARD (COMPETENCY REDUCER)
----------------------------------------
The N+1 problem is one of the most common performance disasters in GraphQL APIs. A compiler that automatically generates optimized SQL from GraphQL queries demonstrates deep understanding of query planning, AST traversal, and SQL semantics — topics covered in systems and database internals interviews.

RECRUITER SHORTLIST SIGNAL

ARCHITECTURE & DATA FLOW
----------------------------------------
GraphQL schema parser building a field dependency graph. Incoming query AST traversal identifying required fields and their relationships. JOIN inference engine generating a single SQL query with all required table joins, column selections, and WHERE clauses. Benchmark comparing N+1 vs compiled query on a 10k-row dataset.
