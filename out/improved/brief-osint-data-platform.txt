ARCHITECTURE & DATA FLOW
----------------------------------------
Scrapy-based distributed crawler with Playwright for JavaScript-rendered pages. Redis Bloom filter for URL deduplication across crawler instances. Kafka queue for discovered URLs with priority queuing. PostgreSQL for structured data storage. Change detection using content hashing with diff computation. Email/Slack alerts on detected changes.
