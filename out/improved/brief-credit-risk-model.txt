----------------------------------------------------------------------

Machine learning credit risk models overcome this barrier by synthesizing transactional banking patterns, behavioral repayment indicators, and alternative cashflow features. ARCHITECTURE & DATA FLOW
----------------------------------------------------------------------
Components:
- Feature Engineering Pipeline (Tools: Python, Pandas): Computes debt-to-income, cashflow volatility, and Weight of Evidence (WoE) monotonic binnings
- Monotonic XGBoost Model (Tools: Python, XGBoost): Trains gradient boosted trees enforcing positive and negative monotonic risk constraints
- Probability Calibration Layer (Tools: Python, Scikit-learn): Transforms raw model margins into well-calibrated default probabilities using Platt scaling
- Adverse Action SHAP Explainer (Tools: Python, SHAP): Extracts top-3 features increasing applicant default probability for regulatory disclosure notices
- Real-Time Underwriting Gateway (Tools: Python, FastAPI): Exposes HTTP scoring route returning credit decisions, default probabilities, and reason codes

Data Flow:
Applicant financial attributes enter via HTTP POST to FastAPI; Feature Pipeline calculates WoE transformed vectors; XGBoost scores risk margins with monotonic constraints; Probability Calibration Layer maps margin to default probability; SHAP Explainer extracts top adverse contributing features; Gateway returns decision (APPROVE, REVIEW, DECLINE) with calibrated probability and top-3 reason codes.

Enforcement Mechanism:
Monotonic constraints enforced during tree building preventing higher income from increasing default probability; automated decision cutoffs routing high-risk applications to manual review.
