PROBLEM STATEMENT
----------------------------------------
Developers search codebases with grep and regex, missing semantically related code. Build a semantic code search engine that parses source code into AST-based chunks, embeds them into vector space, and returns semantically similar code functions in response to natural language queries.

ARCHITECTURE & DATA FLOW
----------------------------------------
Tree-sitter AST parser extracting function-level chunks from Python/JavaScript/TypeScript code. CodeBERT/OpenAI embeddings for each chunk. Qdrant/ChromaDB vector store with metadata (file path, language, function name). FastAPI semantic search endpoint. React UI with syntax-highlighted results.
