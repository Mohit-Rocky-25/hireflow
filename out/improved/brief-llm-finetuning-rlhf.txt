PROBLEM STATEMENT
----------------------------------------
Pre-trained LLMs are helpful but not aligned with human values or task preferences without additional training. Reinforcement Learning from Human Feedback (RLHF) is what makes ChatGPT helpful rather than harmful. Build a simplified RLHF pipeline: reward model training, PPO fine-tuning, and alignment evaluation.

ARCHITECTURE & DATA FLOW
----------------------------------------
SFT (Supervised Fine-Tuning) baseline on task demonstrations. Human preference dataset collection UI. Reward model trained on preference pairs using Bradley-Terry model. PPO (Proximal Policy Optimization) fine-tuning loop with KL penalty constraining divergence from SFT model. Alignment evaluation on held-out preference test set.
