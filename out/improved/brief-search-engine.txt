ARCHITECTURE & DATA FLOW
----------------------------------------
Go implementation with an inverted index stored as a sorted map of term → posting list. Tokenization pipeline (stemming, stop word removal, n-gram generation). BM25 scoring with field weighting. Boolean AND/OR/NOT query parsing. Concurrent indexing with goroutines. HTTP query interface.
