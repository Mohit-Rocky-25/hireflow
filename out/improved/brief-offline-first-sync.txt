----------------------------------------
Field workers and mobile users frequently lose internet connectivity, leading to dropped changes and stuck form submits. Build an offline-first data synchronization protocol with client-side optimistic mutations and server vector clock conflict resolution.

ARCHITECTURE & DATA FLOW
----------------------------------------
Client stores mutations in local IndexedDB / SQLite with Lamport logical timestamps. When network connectivity resumes, an event sync engine batches mutations to a GraphQL backend which resolves conflicting updates via Last-Write-Wins or custom merge functions.
