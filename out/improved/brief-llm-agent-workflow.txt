ARCHITECTURE & DATA FLOW
----------------------------------------
ReAct (Reasoning + Acting) loop implemented with LangChain/custom Python. Agent receives a goal, generates a plan with tool-call intents, executes tools (web search, calculator, database query, code interpreter), validates outputs, and retries on tool failure. Uses structured JSON output parsing with Pydantic validation.
